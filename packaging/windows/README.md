# Windows Packaging Notes

## Overview

The Windows distribution bundles the compiled TypeScript output (`dist/`),
production `node_modules/`, and a portable Node.js runtime (`node/`) into a
single installer produced by NSIS.

No system-wide Node.js installation is required on the end-user machine.

## Directory layout inside the installer

```
$PROGRAMFILES64\OpenClaw Safe\
  dist\           — compiled TypeScript (dist/app.js is the entry point)
  node_modules\   — production runtime dependencies
  node\           — portable Node.js 20 LTS (node.exe, etc.)
  launcher.bat    — sets %APP_DIR% and runs node.exe dist\app.js
  Uninstall.exe   — generated by NSIS
```

User data is **never** stored inside Program Files.
It lives in `%APPDATA%\OpenClaw-Safe\` (managed by `src/core/paths.ts`).

## Requirements (build machine)

| Tool | Version | Notes |
|------|---------|-------|
| Windows | 10 / 11 | Build must run on Windows for NSIS |
| Node.js | 20 LTS | `node` and `npm` in PATH |
| NSIS | 3.x | [nsis.sourceforge.io](https://nsis.sourceforge.io/) |
| 7-Zip | any | Optional; fallback uses PowerShell `Compress-Archive` |

## Building

From the repository root:

```powershell
pwsh packaging\windows\build.ps1
```

The script:
1. Compiles TypeScript (`npm run build`)
2. Installs production deps only (`npm ci --omit=dev`)
3. Creates `dist-pkg/` with `dist/`, `node_modules/`, `launcher.bat`
4. Zips `dist-pkg/` → `OpenClaw-Safe-win32.zip`
5. If `makensis` is in PATH, builds `OpenClaw-Safe-Setup.exe`

The bundled Node runtime (`dist-pkg\node\`) is **not** created by the local
build script — it is downloaded in the GitHub Actions workflow (see
`.github/workflows/release-windows.yml`). For a local build, copy a portable
Node.js 20 distribution into `dist-pkg\node\` manually before running
`makensis`.
